\## 2. Ringkasan Dasar Teori

* Basis Data dan Sistem Manajemen Basis Data

Basis Data adalah kumpulan data yang saling berhubungan dan disimpan secara terorganisasi agar dapat dipakai bersama oleh banyak pengguna dan aplikasi. Perangkat lunak yang mengelolanya disebut Sistem Manajemen Basis Data (*database management system,* DBMS). Database Management System (DBMS) atau sistem manajemen basis data adalah software yang digunakan untuk mengelola dan mengatur data dalam database. Sehingga ini akan memungkinkan pengguna untuk menyimpan, memodifikasi, dan mengambil data dengan cara yang efisien dan terstruktur. Ini adalah elemen penting dalam dunia teknologi informasi, di mana pengelolaan data menjadi kunci untuk banyak operasi bisnis dan penelitian. Salah satu peran utama DBMS adalah menyediakan antarmuka yang memudahkan pengguna dalam berinteraksi dengan database.

* Arsitektur Klien-Server MariaDB

MariaDB adalah sebuah sistem manajemen basis data open source yang dikembangkan sebagai alternatif dari MySQL. Sistem ini berfungsi untuk mengelola database relasional dengan lebih fleksibel dan efisien. MariaDB sering digunakan dalam berbagai aplikasi, mulai dari situs web kecil hingga aplikasi bisnis besar. Pada konteks web, MariaDB digunakan untuk menyimpan dan mengambil data secara cepat, memungkinkan aplikasi web untuk berjalan dengan lancar. Pemahaman tentang MariaDB menjadi penting bagi siapa pun yang terlibat dalam pengembangan web karena fungsionalitas dan fleksibilitasnya.

* XAMPP

XAMPP merupakan paket software open-source yang menyediakan lingkungan server lokal untuk pengembangan web. Paket ini dibuat untuk mendukung sistem operasi lintas platform sehingga dapat digunakan oleh pengembang web baik di Windows, Linux, maupun MacOS. XAMPP terdiri dari beberapa komponen utama, yaitu: Cross Platform (X), Apache (A), MySQL/MariaDB (M), PHP (P), dan Perl (P). Masing-masing komponen ini memiliki peran tertentu dalam menciptakan lingkungan pengembangan web yang efisien dan efektif.

* Server: CLI dan phpMyAdmin

Command line interface (CLI) adalah tampilan berbasis teks yang memungkinkan pengguna berkomunikasi langsung dengan sistem operasi melalui perintah yang diketik menggunakan keyboard. CLI biasanya digunakan melalui terminal, command prompt, atau shell, dan hingga kini masih menjadi alat utama untuk banyak administrator sistem, developer, dan pengguna tingkat lanjut, sedangkan phpMyAdmin adalah perangkat lunak gratis open-source yang ditulis dengan PHP, berfungsi sebagai antarmuka web untuk administrasi database MySQL dan MariaDB. phpMyAdmin menyediakan cara mudah mengelola basis data (database) lewat browser, tanpa harus mengetik perintah SQL di command line.

* Akun, Host, dan Hak Akses

Di MariaDB, akun tidak hanya ditentukan oleh nama pengguna, tetapi oleh pasangan pengguna@host. 'root'@'127.0.0.1' adalah dua akun berbeda, masing-masing dengan password dan hak aksesnya sendiri. Bawaan XAMPP, akun root dibuat tanpa password agar mudah dipakai. Akun root hanya untuk administrasi, sedangkan pekerjaan harian memakai akun kerja yang hanya berhak atas satu basis data.

* Git

Git adalah salah satu sistem pengontrol versi (Version Control System) yang diciptakan oleh Linus Torvalds pada tahun 2005. Alat ini dirancang untuk mencatat setiap perubahan yang terjadi pada file dalam proyek perangkat lunak. Berbeda dengan sistem pengontrol versi terpusat, Git dikenal sebagai distributed version control system, yang artinya semua orang yang terlibat dalam proyek memiliki salinan lengkap dari database Git.

\## 4. Jawaban Titik Analisis

Titik Analisis 1

Label MySQL di XAMPP Control Panel itu adalah label yang lama. Sejak adanya XAMPP 5.5, yang dijalankan sebenarnya MariaDB. Konsekuensi jika mencari solusi galat di internet dengan keyword "MySQL" hasilnya menjadi tidak cocok, MariaDB memiliki mesin penyimpanan Aria, file aria\_log, dan pesan error yang tidak ada di MySQL. Jika solusi MySQL diterapkan langsung ke MariaDB tanpa diperiksa, solusi tersebut bisa saja tidak bekerja.

Dokumentasi MySQL masih relevan untuk SQL standar: CREATE, SELECT, INSERT, UPDATE, GRANT karena sintaks dasar masih sama. Namun, jika masalah berkaitan dengan fitur khusus MariaDB, konfigurasi, atau pesan galat yang berbeda sebaiknya merujuk langsung ke dokumentasi MariaDB.



Titik Analisis 2

Dengan menggunakan perintah mysql -u root tanpa -p muncul pesan galat ERROR 1045 (28000): Access denied for user ;root'@'localhost' (using password: NO), pada bagian (using password: NO) pesan itu memberitahu bahwa klien tidak mengirim password sama sekali.



Titik Analisis 3

information\_schema tetap terlihat oleh mhs\_123 karena bukan database fisik, tetapi view sistem virtual untuk melihat metadata. Semua pengguna dapat melihat tanpa harus memiliki hak akses database sistem, sedangkan mysql ditolak dikarenakan berisi data hak akses. Muncul pesan ERROR 10441 karena pengguna tersebut tidak memiliki hak akses yang diperlukan terhadap database mysql.

Kode galat 1044 terjadi ketika pengguna sudah berhasil login, tetapi tidak memiliki izin untuk mengakses database yang diminta, sedangkan kode galat 1045 terjadi ketika proses login gagal, misalnya karena username, password, atau host tidak sesuai.



Titik Analisis 4

Mode cookie lebih aman karena tidak menyimpan password di file, password diminta setiap kali masuk phpMyAdmin dan hanya disimpan sementara di session browser. Jadi kalau file config bocor, password tetap aman. Berbeda dengan mode config yang hanya menyimpan password dalam bentuk teks biasa di dalam file. Siapa saja dapat langsung login sebagai root.

\## 7. Pembahasan dan Kendala

Beberapa kendala yang ditemukan yaitu:

1. Database masih versi 123

Saat SHOW DATABASES; masih muncul database versi lama seperti, kopma\_123, klinik\_123, kopma\_23 sebelum diganti menjadi kopma\_035, klinik\_035 mengikuti NIM milik pengguna. Akibatnya isi file p01\_lingkungan\_25430035.sql diganti menjadi 035, kemudian dijalankan ulang dengan mysql -u root -p < p01\_lingkungan\_25430035.sql menggunakan password root.

2\. Double Database

Karena perbaikan dari file lama, database menjadi ganda. Sehingga dilakukan pembersihan dengan DROP DATABASE IF EXISTS kopma\_123, klinik\_123, kopma\_23 digantikan kopma\_035 dan klinik\_035.

3\. Galat (ERROR 1045)

Terdapat ERROR 1045 (28000): Access denied for user 'mhs\_035'@'localhost' saat tes login 'mhs\_035'. Kendala ini terjadi karena password yang digunakan tertukar dengan password root (password sengaja dibedakan).

* Kode
1. ERROR 1045 : Password yang digunakan salah sehingga melakukan pemeriksaan: SELECT User, Host FROM mysql.user WHERE User LIKE'%\_035';
2. ERROR 1007/1396 : Database sudah ada, akibatnya file tetap error setelah di run dua kali atau tidak idempotent. Fie dapat diperbaiki dengan menggunakan IF NOT EXISTS pada CREATE DATABASE dan CREATE USER.
3. ERROR 1044 : Kode ini bukan galat, kode ini menjadi bukti bahwa least privilege dev\_035 tidak bisa akses kopma\_035 berhasil.
